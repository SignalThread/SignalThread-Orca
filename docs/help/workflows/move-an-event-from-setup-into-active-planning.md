# Move an Event from Setup into Active Planning

Establish the core records and ownership needed for weekly planning.

## Objective

Move an event from an empty workspace into a weekly planning rhythm with owners, dates, forecasts, sessions, and people records.

## Orca Modules

- Event Settings
- Roadmap
- Budget
- Run of Show
- Directory

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Confirm event identity, dates, timezone, and lifecycle context.
2. Build Roadmap work by planning stage, owner, date, priority, and dependency.
3. Establish Budget categories, targets, initial forecast lines, and approval expectations.
4. Create the working Run of Show and room list.
5. Load Directory, Attendees, and Speakers from reliable sources.
6. Review the Event Command Center and resolve obvious missing-data signals.

## What Complete Means

- Roadmap has owners and dates for active workstreams.
- Budget has an initial forecast and category structure.
- Run of Show and people records are usable for weekly planning.
- The Event Command Center reflects source records without unexplained gaps.

## Planner Tips

- Move into active planning when ownership and review cadence exist, not when every detail is complete.
- Resolve organization access before inviting contributors to update modules.
