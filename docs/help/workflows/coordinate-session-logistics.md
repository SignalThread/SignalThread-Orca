# Coordinate Session Logistics

Bring schedule, speaker, AV, F&B, staffing, room, and budget context together for each session.

## Objective

Review one session across schedule, speakers, AV, F&B, staffing, files, onsite details, and linked costs.

## Orca Modules

- Run of Show
- Session Workspace
- Budget
- F&B Catalog
- Docs

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Open the session workspace from Run of Show.
2. Confirm date, time, room, type, and assigned speakers.
3. Review AV, F&B, staffing, and other requirement sections.
4. Assign approved F&B catalog items where applicable.
5. Link operational requirements to budget lines when the supported control is available.
6. Store approved diagrams or production files in Docs.
7. Review conflicts and unresolved readiness before the production meeting.

## What Complete Means

- The session workspace reflects the agreed schedule and assigned speakers.
- AV, F&B, staffing, setup, and budget links have been reviewed together.
- Conflicts and missing requirements have named owners.

## Planner Tips

- Review one session across all disciplines instead of maintaining separate departmental copies.
- Use budget links for cost-bearing requirements so operations and finance stay connected.
