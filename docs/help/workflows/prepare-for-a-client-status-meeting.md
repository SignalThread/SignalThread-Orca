# Prepare for a Client Status Meeting

Assemble a current, decision-focused event status without maintaining a parallel tracker.

## Objective

Prepare a decision-focused client review using current source-module records and clearly owned exceptions.

## Orca Modules

- Event Command Center
- Roadmap
- Budget
- Run of Show
- Speakers
- Docs

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Open the Event Command Center and identify the largest current exceptions.
2. Review overdue, blocked, critical-path, and near-term Roadmap items.
3. Review Budget forecast, actual, variance, and pending approvals.
4. Scan Run of Show conflicts and sessions missing key requirements.
5. Review speaker readiness and pending document or profile work.
6. Open decision documents in Docs and prepare a short list of decisions, owners, and due dates.

## What Complete Means

- The meeting packet contains current source-module figures, not stale exports.
- Every requested decision has context, an owner, and a due date.
- Budget, schedule, speaker, and document exceptions are ready to open in Orca during the meeting.

## Planner Tips

- Lead with decisions and exceptions rather than reading every dashboard card.
- Open disputed values in their source module before committing to a follow-up.
