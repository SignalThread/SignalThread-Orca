# Conduct a Weekly Event Health Review

Run a repeatable cross-module check of event risk, readiness, and financial health.

## Objective

Triage portfolio and event exceptions in a consistent order, then leave each open item with an owner and source record.

## Orca Modules

- Account Command Center
- Action Center
- Event Command Center
- Roadmap
- Budget
- Run of Show
- Speakers

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Start at the account-level Command Center and compare visible events by health.
2. Open Action Center for portfolio Risks, Approvals, Deadlines, and Budget exposure.
3. Enter the selected event and review Event Command Center signals.
4. Validate Roadmap risk, Budget variance, Run of Show conflicts, and speaker readiness in their source modules.
5. Record ownership and dates in Roadmap or the applicable source record.
6. Recheck Action Center after updates to confirm the remaining portfolio exceptions.

## What Complete Means

- Portfolio exceptions have been triaged to the correct event and module.
- Roadmap blockers, budget exposure, schedule conflicts, and speaker gaps have current owners.
- Remaining Action Center items represent real open work.

## Planner Tips

- Use the same review order each week so omissions are visible.
- Review the nearest and highest-risk events first, then scan the rest of the portfolio.
