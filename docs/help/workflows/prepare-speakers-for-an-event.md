# Prepare Speakers for an Event

Move speakers from initial confirmation through profile, content, logistics, and onsite readiness.

## Objective

Move each speaker from initial identity and invitation through profile, session, document, portal, and onsite readiness.

## Orca Modules

- Speakers
- Speaker Intake
- Speaker Portal
- Run of Show
- Docs

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Create or import speaker records and confirm email identity.
2. Assign speakers to sessions and resolve schedule conflicts.
3. Send secure intake links for profile updates and review submissions.
4. Generate speaker portal links and preview the portal before sending.
5. Create required document requests and review submitted files.
6. Track presentation, travel, dietary, and onsite gaps through speaker readiness.
7. Confirm final sessions, arrival instructions, and approved materials before onsite.

## What Complete Means

- Speaker identity, profile, sessions, and portal access are correct.
- Required documents and presentations have a clear review state.
- Travel, dietary, onsite, and scheduling gaps have owners before arrival.

## Planner Tips

- Request profile information before public copy freezes.
- Preview each portal before sharing its one-time token link.
