# Build and Review a Run of Show

Create a schedule that supports program design and production delivery.

## Objective

Build a conflict-reviewed schedule whose sessions contain the people, rooms, and operational requirements needed for delivery.

## Orca Modules

- Run of Show
- Sessions
- Speakers
- F&B
- Room Set & Seating

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Create or import sessions with accurate event dates, times, and rooms.
2. Use Board view to review schedule shape, transitions, overlaps, and room utilization.
3. Use List view to find missing speakers, AV, F&B, staffing, or other details.
4. Assign speakers and review conflicts.
5. Add session requirements and approved F&B assignments.
6. Review Room Set & Seating only where available; retain approved diagrams in Docs in production.
7. Conduct a final date-by-date and room-by-room review.

## What Complete Means

- Every session has a date, start, end, and room or an explicit unresolved owner.
- Speaker and room conflicts have been reviewed.
- Required AV, F&B, staffing, and production details are recorded or assigned for follow-up.

## Planner Tips

- Use Board for schedule shape and List for completeness.
- Include operational holds and rehearsals when they consume rooms or people.
