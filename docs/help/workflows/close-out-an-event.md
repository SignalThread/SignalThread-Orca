# Close Out an Event

Reconcile financial, program, document, and planning records after delivery.

## Objective

Reconcile final financial and operational records, preserve the files that explain delivery, and close or reassign follow-up work.

## Orca Modules

- Budget
- Roadmap
- Run of Show
- Docs
- Speakers

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Update Budget actuals and resolve or document remaining approvals.
2. Close completed Roadmap work and record unresolved follow-up with owners and dates.
3. Review Run of Show and session records for final operational changes worth preserving.
4. Store final reports, invoices, decks, and approved documents in Docs.
5. Review speaker files and communications that should remain with the event record.
6. Export required budget data for external reconciliation.
7. Confirm event settings and lifecycle handling with the responsible administrator; account reporting and Event Activity remain incomplete surfaces.

## What Complete Means

- Budget actuals and unresolved approvals are reconciled or documented.
- Final files are stored in Docs Hub and Roadmap follow-up is closed or reassigned.
- Run of Show and speaker records preserve final delivery context.
- Required exports are dated and tied back to the live event record.

## Planner Tips

- Close financial and document records before institutional knowledge disperses.
- Preserve final operational changes that will help a future event team understand what occurred.
