# Build a New Event from Existing Spreadsheets

Create a usable event workspace from existing Run of Show, budget, and timeline files.

## Objective

Create a usable event workspace from existing spreadsheets, then reconcile every imported record and exception against the source files.

## Orca Modules

- Import Planning Spreadsheets
- Run of Show
- Budget
- Roadmap

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Collect the cleanest source workbook or CSV for each planning area.
2. Create the event and enter venue dates and timezone.
3. Choose spreadsheet import, assign sheets to Run of Show, Budget, or Timeline, and map required fields.
4. Review Preview records, Issues, Mapping, skipped rows, and Will create totals.
5. Create the workspace, then verify dates and rooms in Run of Show, totals in Budget, and owners and dependencies in Roadmap.
6. Resolve import conflicts before inviting a wider planning team.

## What Complete Means

- The event has the intended Run of Show, Budget, and Roadmap records.
- Every skipped or invalid row has been reconciled against the source.
- Imported times, rooms, amounts, owners, and due dates have been spot-checked in their source modules.

## Planner Tips

- Import the cleanest source tab first; decorative summary tabs create avoidable mapping work.
- Keep the original workbook unchanged until record counts and exceptions are reconciled.
