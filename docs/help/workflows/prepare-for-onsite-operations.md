# Prepare for Onsite Operations

Turn the planning workspace into a reliable operating picture for event delivery.

## Objective

Create a reliable operating picture for event delivery, with every open onsite issue tied to an owner and source record.

## Orca Modules

- Run of Show
- Session Workspace
- Speakers
- Docs
- Budget

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Review Run of Show by event date, room, and time for handoffs and conflicts.
2. Confirm every operational session has required people and resources.
3. Review speaker onsite details, arrivals, dietary needs, and final files.
4. Place current production documents and approved diagrams in Docs.
5. Confirm urgent budget commitments and approval state.
6. Identify who owns each open issue and where its source record lives.
7. Use the Event Command Center and source modules for live review; Event Activity is not yet an audit log.

## What Complete Means

- Run of Show is reviewed by date, room, and operational handoff.
- Session resources and speaker onsite details are current.
- Current production documents are identifiable in Docs Hub.
- Every open onsite issue has an owner and source record.

## Planner Tips

- Use List to find missing resources, then Board to rehearse room-and-time flow.
- Do not rely on Event Activity as an audit trail; it remains Coming soon.
