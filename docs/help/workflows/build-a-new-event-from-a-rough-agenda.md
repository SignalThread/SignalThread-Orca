# Build a New Event from a Rough Agenda

Turn agenda text into an initial Run of Show that can be reviewed and expanded.

## Objective

Turn an incomplete agenda into a reviewable Run of Show without guessing at missing schedule or room information.

## Orca Modules

- Event Builder
- Run of Show

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Create an event and enter accurate dates and timezone.
2. Choose the pasted-agenda starting point and paste the agenda text.
3. Review detected sessions and resolve missing date or time information.
4. Create the workspace and open Run of Show.
5. Add rooms, session types, speakers, and operational requirements.
6. Review the Board for overlaps and gaps, then use List for missing-field cleanup.

## What Complete Means

- Every usable agenda line appears on the correct event date in Run of Show.
- Missing rooms, end times, session types, and speakers are identified for follow-up.
- Board review shows no unexplained overlap or room transition.

## Planner Tips

- Normalize date and time notation before pasting the agenda.
- Use List after creation to find missing fields that are hard to spot on the Board.
