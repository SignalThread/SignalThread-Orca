# Review Event Financial Health

Assess forecast, actuals, variance, targets, exposure, and pending approvals.

## Objective

Explain current financial exposure from Budget records and route the lines requiring a decision or correction.

## Orca Modules

- Budget Dashboard
- Full Budget Grid
- Action Center

## Before You Begin

- Confirm the event dates, timezone, and organization context.
- Gather the current source files and identify the planner responsible for each planning area.

## Workflow

1. Open the Budget Dashboard and compare forecast with actual.
2. Review category targets and large category variances.
3. Open the Full Budget Grid and filter to the lines driving the variance.
4. Check vendor, group, session, status, and approval context.
5. Review pending submissions and resolve approvals in the source line.
6. Export a summary or line-item CSV when an external review file is required.
7. Document decisions in the budget record and update forecast or actual values as appropriate.

## What Complete Means

- Forecast, Actual / Committed, and variance have been reviewed at category and line level.
- Pending approvals and large exposures have decision owners.
- Any exported report matches the current event and filter scope.

## Planner Tips

- Start with category variance, then inspect contributing lines.
- Do not describe committed values as paid unless the line data supports that statement.
