# Use Tasks

Understand the current disabled state of Orca's generic tasking interface.

## Overview

Generic Tasks is not available in the current planner workspace. There is no Tasks navigation item or supported generic task queue.

## When You’ll Use It

- Open this guide when you need to understand the current disabled state of Orca's generic tasking interface.
- Return when a notification, approval, or availability question needs to be traced to its source record.

## Before You Begin

- Confirm the organization and event before following a linked item.
- Use the source module's access and status rules for any change or decision.

## Open Tasks

1. There is no Tasks navigation item while generic tasking is disabled.
2. Use **Roadmap** for dated planning work and source-module approval controls for decisions.

## Use Available Planning Workflows

1. Use Roadmap for event planning items, owners, dependencies, dates, priority, and status.
2. Use Action Center for cross-event risks, approvals, deadlines, and budget exposure.
3. Use source-module approvals for Budget, Docs, Marketing, and speaker submissions.

## Understand Important Concepts

- Generic Tasks is not available in the current planner workspace.

## In-product Helper Text

> Generic Tasks is not currently available.

## Planner Tips

- Place event deliverables with dates and dependencies in Roadmap rather than waiting for generic Tasks.

## Best Practices

- Use Roadmap for dated work, owners, status, priority, and dependencies.
- Never use a task or Roadmap status as a substitute for a Budget, document, marketing, or speaker-submission approval.

## Troubleshooting

### A control is missing or disabled

Open the linked source module and check its record state; summary surfaces do not override source permissions.

## Frequently Asked Questions

### Where is the system of record?

The linked source module owns the record. Notifications, Action Center, and disabled Tasks do not replace module approvals.
