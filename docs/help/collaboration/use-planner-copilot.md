Understand the current gated state of Orca's contextual planning assistant.

Planner Copilot is a gated preview and is not available in the current planner workspace. There is no supported launcher, prompt set, or action workflow.

- Open this guide when you need to understand the current gated state of Orca's contextual planning assistant.
- Return when a notification, approval, or availability question needs to be traced to its source record.

## Open Planner Copilot

1. Planner Copilot is disabled in the current feature configuration.

## Understand the Preview

1. Do not expect a Planner Copilot launcher in the current workspace.
