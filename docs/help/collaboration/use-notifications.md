# Use Notifications

Open recent notifications, clear unread state, and return to linked work.

## Overview

The list loads up to 20 recent notifications. There is no current Mark all read control or notification preferences page.

## When You’ll Use It

- Open this guide when you need to open recent notifications, clear unread state, and return to linked work.
- Return when a notification, approval, or availability question needs to be traced to its source record.

## Before You Begin

- Confirm the organization and event before following a linked item.
- Use the source module's access and status rules for any change or decision.

## Open Notifications

1. Select **Notifications** in the application header.
2. Select a notification row to mark it read and follow its link, when present.

## Open a Notification

1. Choose the Notifications bell in the header.
2. Review the unread count and recent list.
3. Select an item to mark it read.
4. If the item has a link, Orca opens the related work after marking it read.

## Understand Important Concepts

- The list loads up to 20 recent notifications. There is no current Mark all read control or notification preferences page.

## In-product Helper Text

> Unread notifications are marked read when you open them.

## Planner Tips

- After opening a notification, confirm the linked event and record before taking action.

## Best Practices

- Confirm the linked event before taking action from a notification.
- If an expected item is absent, check Action Center or the source module instead of waiting on the menu.

## Troubleshooting

### A control is missing or disabled

Open the linked source module and check its record state; summary surfaces do not override source permissions.

## Frequently Asked Questions

### Where is the system of record?

The linked source module owns the record. Notifications, Action Center, and disabled Tasks do not replace module approvals.
