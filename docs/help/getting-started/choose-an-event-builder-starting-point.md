# Choose an Event Builder Starting Point

Choose between a template, spreadsheets, a pasted agenda, or an empty event workspace.

## Overview

Templates create starter sessions, a budget shell, and timeline tasks. They do not replace planner review.

A pasted agenda targets the Run of Show. Spreadsheet mapping can target Run of Show, Budget, and Timeline.

## When You’ll Use It

- Open this guide when you need to choose between a template, spreadsheets, a pasted agenda, or an empty event workspace.
- Use it during event setup and whenever a planner needs to recheck scope or navigation.

## Before You Begin

- You need an Orca account and access to the organization that owns the event.
- Gather the event dates, timezone, and any source material required by the task.

## Open an Event Builder Starting Point

1. Select **Create Event** from the account **Command Center**.
2. Complete **Event details**, select **Continue**, then choose **Upload Spreadsheet**, **Paste Agenda**, **Use Template**, or **Start Blank**.

## Choose a Source

1. Complete Event details and continue to Choose a starting point.
2. Choose a starter template for a Conference, Trade Show, Gala / Awards, Training, Workshop, or Corporate Meeting when you want a planning shell.
3. Choose spreadsheet import when Run of Show, Budget, or Timeline data already exists.
4. Choose the pasted-agenda option when your source is a rough text agenda.
5. Use an empty starting point when you want to build records manually.

## Understand Important Concepts

- Templates create starter sessions, a budget shell, and timeline tasks. They do not replace planner review.
- A pasted agenda targets the Run of Show. Spreadsheet mapping can target Run of Show, Budget, and Timeline.

## In-product Helper Text

> Starting points seed the workspace; you can continue editing every imported or template-created record.

## Planner Tips

- Choose the source with the most reliable structure. A clean budget workbook and a rough agenda can be handled separately after event creation.

## Best Practices

- Choose the structured source with the fewest cleanup exceptions.
- Use **Start Blank** only when no reliable agenda, workbook, or suitable template exists.

## Troubleshooting

### A control is missing or disabled

Confirm you have selected an organization, have access to the event, and completed every required field shown on the page.

## Frequently Asked Questions

### Where is the system of record?

The selected organization and event determine scope. Once inside an event, the owning event module is authoritative.
