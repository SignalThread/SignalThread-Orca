# Create Your First Event

Create an event workspace with the correct dates, timezone, and planning starting point.

## Overview

The builder creates one event workspace. Imported Run of Show, Budget, and Timeline records are scoped to that event.

Additional Docs accepts PDF, DOC/DOCX, JPG, and PNG files up to 50 MB each.

## When You’ll Use It

- Open this guide when you need to create an event workspace with the correct dates, timezone, and planning starting point.
- Use it during event setup and whenever a planner needs to recheck scope or navigation.

## Before You Begin

- You need an Orca account and access to the organization that owns the event.
- Gather the event dates, timezone, and any source material required by the task.

## Open Your First Event

1. From the account **Command Center**, select **Create Event**.
2. On **Create event workspace**, complete **Event details**, **Choose a starting point**, and **Review & create**.

## Enter Event Details

1. From the account-level Command Center, choose New Event.
2. Enter the Event name, Start date, End date, and Timezone.
3. Correct any validation message before continuing to Choose a starting point.

## Review and Create

1. Choose a starting point for the event.
2. Review detected records, issues, and mappings when your source contains planning data.
3. Add optional supporting documents if needed.
4. Choose the create action only after the event dates and import preview are correct.

## Understand Important Concepts

- The builder creates one event workspace. Imported Run of Show, Budget, and Timeline records are scoped to that event.
- Additional Docs accepts PDF, DOC/DOCX, JPG, and PNG files up to 50 MB each.

## In-product Helper Text

> Event dates and timezone establish the calendar context for the workspace.

## Planner Tips

- Use the event venue timezone, not the planner's home-office timezone. Session times and onsite coordination depend on it.

## Best Practices

- Use the venue timezone and final contracted event dates before importing timed sessions.
- Review imported counts before inviting the wider team into the workspace.

## Troubleshooting

### A control is missing or disabled

Confirm you have selected an organization, have access to the event, and completed every required field shown on the page.

## Frequently Asked Questions

### Where is the system of record?

The selected organization and event determine scope. Once inside an event, the owning event module is authoritative.
