# Understand Organizations and Access

Understand how organization context and event roles determine what you can see and change.

## Overview

Organization access determines the account and event set you can reach. Event-level roles can further limit editing.

Platform administration is reserved for SUPER_ADMIN users and is not a normal planner workspace.

## When You’ll Use It

- Open this guide when you need to understand how organization context and event roles determine what you can see and change.
- Use it during event setup and whenever a planner needs to recheck scope or navigation.

## Before You Begin

- Open the correct organization and event.
- Confirm you have edit access before changing records.

## Open Organizations and Access

1. Sign in and check the organization name at the bottom of the account sidebar.
2. Open an event and confirm that its name and dates appear in the event selector.

## Check Your Organization Context

1. Sign in and open the account-level Command Center.
2. If Orca asks for an organization context, select the organization that owns the event.
3. Confirm the expected events appear before beginning work.

## Work With Event Permissions

1. Open an event you can access.
2. Viewers can read supported event pages but cannot change protected records.
3. Ask an organization administrator to adjust access when an edit control is unavailable for work you own.

## Understand Important Concepts

- Organization access determines the account and event set you can reach. Event-level roles can further limit editing.
- Platform administration is reserved for SUPER_ADMIN users and is not a normal planner workspace.

## In-product Helper Text

> Read-only access lets you review event work without changing records.

## Planner Tips

- Use viewer access for stakeholders who need status visibility but should not change the planning record.

## Best Practices

- Give stakeholders Viewer access when they need visibility without editing rights.
- Resolve organization access before creating records; a duplicate event is not an access workaround.

## Troubleshooting

### I can see Orca but no events

Confirm that the correct organization is selected and that you have been granted access to an event in it.

## Frequently Asked Questions

### Where is the system of record?

The selected organization and event determine scope. Once inside an event, the owning event module is authoritative.
