# Understand Event Workspace Navigation

Use the event sidebar, module navigation, and event selector to work within the correct event.

## Overview

Staffing and Exhibitors are labeled Coming soon in event navigation.

Marketing appears under **Management**. F&B Catalog remains a direct preview route outside event navigation.

Activity is a Coming soon page.

## When You’ll Use It

- Open this guide when you need to use the event sidebar, module navigation, and event selector to work within the correct event.
- Use it during event setup and whenever a planner needs to recheck scope or navigation.

## Before You Begin

- You need an Orca account and access to the organization that owns the event.
- Gather the event dates, timezone, and any source material required by the task.

## Open Event Workspace Navigation

1. Open an event from **Event Snapshot** or **Search events**.
2. Use **Planning** for Roadmap, Budget, Run of Show, and Event Directory; use **Management** for Marketing and Documents.

## Open Event Modules

1. Open an event from the account-level Command Center.
2. Use Roadmap, Budget, and Run of Show for planning.
3. Expand Directory to reach Speakers and Attendees.
4. Open **Documents** or **Settings** for event files and configuration.

## Understand Important Concepts

- Staffing and Exhibitors are labeled Coming soon in event navigation.
- Marketing appears under **Management**. F&B Catalog remains a direct preview route outside event navigation.
- Activity is a Coming soon page.

## In-product Helper Text

> The event sidebar is scoped to the event named at the top of the workspace.

## Planner Tips

- Keep one browser tab at the Event Command Center during status meetings and open detailed modules in additional tabs as questions arise.

## Best Practices

- Use Event Directory for canonical people; open Attendees and Speakers for role-specific work.
- Remember that F&B Catalog remains a direct preview route and is not part of event navigation.

## Troubleshooting

### A control is missing or disabled

Confirm you have selected an organization, have access to the event, and completed every required field shown on the page.

## Frequently Asked Questions

### Where is the system of record?

The selected organization and event determine scope. Once inside an event, the owning event module is authoritative.
