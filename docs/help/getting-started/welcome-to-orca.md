# Welcome to Orca

Learn how Orca organizes event planning work across your portfolio and event workspaces.

## Overview

The account-level Command Center summarizes every event you can access. The Event Command Center summarizes one event.

An organization controls which events and administrative areas are available to you.

## When You’ll Use It

- Open this guide when you need to learn how Orca organizes event planning work across your portfolio and event workspaces.
- Use it during event setup and whenever a planner needs to recheck scope or navigation.

## Before You Begin

- You need an Orca account and access to the organization that owns the event.
- Gather the event dates, timezone, and any source material required by the task.

## Open Welcome to Orca

1. After sign-in, Orca opens the account-level **Command Center**.
2. Select an event from **Event Snapshot** or use **Search events** to enter its workspace.

## Orient Yourself

1. Open the account-level Command Center after sign-in.
2. Use the event list or event launcher to open an event.
3. Inside the event, use Roadmap, Budget, and Run of Show for the core planning work.
4. Use Directory, Attendees, and Speakers for people and program records.
5. Return to the Orca logo or account navigation when you need a portfolio view.

## Understand Important Concepts

- The account-level Command Center summarizes every event you can access. The Event Command Center summarizes one event.
- An organization controls which events and administrative areas are available to you.

## In-product Helper Text

> Command Center shows portfolio health. Open an event for detailed planning.

## Planner Tips

- Start a weekly review at the account level, then move into the event with the highest risk or nearest date.

## Best Practices

- Start portfolio reviews in the account Command Center; enter an event only when you need its detailed record.
- Do not use dashboard summaries as a substitute for updating Roadmap, Budget, Run of Show, Documents, or people records.

## Troubleshooting

### A control is missing or disabled

Confirm you have selected an organization, have access to the event, and completed every required field shown on the page.

## Frequently Asked Questions

### Where is the system of record?

The selected organization and event determine scope. Once inside an event, the owning event module is authoritative.
