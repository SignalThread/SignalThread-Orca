# Navigate Orca

Move between portfolio views, event workspaces, and event modules without losing context.

## Overview

Portfolio pages combine information across visible events. Event pages are scoped to the selected event.

Some direct-access pages are not listed in navigation; their documentation calls this out.

## When You’ll Use It

- Open this guide when you need to move between portfolio views, event workspaces, and event modules without losing context.
- Use it during event setup and whenever a planner needs to recheck scope or navigation.

## Before You Begin

- You need an Orca account and access to the organization that owns the event.
- Gather the event dates, timezone, and any source material required by the task.

## Open Navigate Orca

1. Use **Command Center**, **Portfolio Reports**, and **Settings** in the account sidebar.
2. Inside an event, use **Command Center**, the **Planning** section, and the **Management** section.
3. Select **Go to Command Center** to return to the account portfolio.

## Move Between Portfolio and Event Work

1. Use the account navigation for Command Center, Portfolio Reports, and Settings.
2. Select an event from the Command Center or event selector.
3. Use the event sidebar to open planning and people modules.
4. Use the event selector to move to another event while staying in the event workspace shell.

## Recognize Your Current Scope

1. Check the event name shown in the event workspace.
2. Confirm whether the page title says Command Center at account or event scope.
3. Before editing, confirm the event name and dates match the event you intend to update.

## Understand Important Concepts

- Portfolio pages combine information across visible events. Event pages are scoped to the selected event.
- Some direct-access pages are not listed in navigation; their documentation calls this out.

## In-product Helper Text

> Use the event selector to change events. Your current module remains visible when the destination supports it.

## Planner Tips

- Before a live planning meeting, open the correct event and module in advance to avoid editing a similarly named event.

## Best Practices

- Confirm the event name and dates before editing, especially when two events have similar names.
- Use the account Command Center for portfolio comparison and the event Command Center for one-event readiness.

## Troubleshooting

### A control is missing or disabled

Confirm you have selected an organization, have access to the event, and completed every required field shown on the page.

## Frequently Asked Questions

### Where is the system of record?

The selected organization and event determine scope. Once inside an event, the owning event module is authoritative.
