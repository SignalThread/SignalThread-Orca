# Understand Notifications

Understand how Orca surfaces unread updates and links you back to relevant work.

## Overview

The menu shows a title, body, relative time, and unread state. There is no separate notification-center page in the current application.

## When You’ll Use It

- Open this guide when you need to understand how Orca surfaces unread updates and links you back to relevant work.
- Use it during event setup and whenever a planner needs to recheck scope or navigation.

## Before You Begin

- You need an Orca account and access to the organization that owns the event.
- Gather the event dates, timezone, and any source material required by the task.

## Open Notifications

1. Select the **Notifications** bell in the application header.
2. The menu loads the 20 most recent notifications and shows the current unread count.

## Review Notification State

1. Find the Notifications bell in the application header.
2. Use the unread badge to see whether new items are waiting.
3. Open the bell to load up to 20 recent notifications.
4. Select a notification to mark it read and open its linked record when a link is available.

## Understand Important Concepts

- The menu shows a title, body, relative time, and unread state. There is no separate notification-center page in the current application.

## In-product Helper Text

> Selecting an unread notification marks it read before opening its linked work.

## Planner Tips

- Treat notifications as prompts to inspect the underlying record; use Action Center for a broader cross-event work queue.

## Best Practices

- Use a notification to reach the source record, then verify its current state there.
- Use Action Center when you need a complete portfolio queue rather than the 20-item recent list.

## Troubleshooting

### A control is missing or disabled

Confirm you have selected an organization, have access to the event, and completed every required field shown on the page.

## Frequently Asked Questions

### Where is the system of record?

The selected organization and event determine scope. Once inside an event, the owning event module is authoritative.
