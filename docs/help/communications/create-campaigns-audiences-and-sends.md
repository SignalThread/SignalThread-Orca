# Create Campaigns, Audiences, and Sends

Create an email campaign, define its recipients, compose a send, preview personalization, and schedule or send it.

## Overview

Scheduling freezes the current audience recipients for that send.

A target send date can be planning-only; the scheduled send time controls actual scheduling.

## When You’ll Use It

- Open this guide when you need to create an email campaign, define its recipients, compose a send, preview personalization, and schedule or send it.
- Return before contacting an audience and before reporting send or compliance outcomes.

## Before You Begin

- Open the correct event and clean the relevant Directory identities before building an audience.
- Confirm you have event editor access and the authority to communicate with the selected recipients.

## Open Campaigns, Audiences, and Sends

1. Open **Marketing**.
2. Select **New campaign**, **Import audience**, or **New email** from the page header.

## Create a Campaign and Audience

1. Open Marketing and create a Campaign.
2. Enter Name, Description, Audience label, optional campaign window, owner, and supported status.
3. Create or import an audience, or create one from selected Directory people.
4. Review recipients and remove records that should not be included.

## Create and Preview an Email Send

1. Create an email send under the campaign.
2. Choose the audience and enter subject, short summary, content, sender settings, and optional button details.
3. Insert supported personalization fields where needed.
4. Choose Preview as recipient and inspect the rendered message and unsubscribe footer.
5. Request approval when required, then schedule or use Send now when the send is eligible.

## Understand Important Concepts

- Scheduling freezes the current audience recipients for that send.
- A target send date can be planning-only; the scheduled send time controls actual scheduling.

## In-product Helper Text

> Scheduling freezes the current recipient snapshot for the send.

## Planner Tips

- Preview as a recipient with sparse data as well as a complete record so missing personalization is caught before approval.

## Best Practices

- Preview personalization using a recipient with sparse data as well as a complete record.
- Remember that scheduling freezes the audience snapshot for that send.

## Troubleshooting

### A control is missing or disabled

Check the send or campaign state, required audience and sender fields, approval state, and your event access.

## Frequently Asked Questions

### Where is the system of record?

Marketing owns campaigns, audience snapshots, sends, approvals, suppressions, and delivery outcomes; Directory owns the underlying person identity.
