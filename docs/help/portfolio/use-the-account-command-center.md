# Use the Account Command Center

Review portfolio health, upcoming events, deadlines, budget signals, and program readiness.

## Overview

This is the account-level Command Center. It is different from the Event Command Center inside one event.

Health indicators summarize current records; they do not replace module-level review.

## When You’ll Use It

- Open this guide when you need to review portfolio health, upcoming events, deadlines, budget signals, and program readiness.
- Return to it during portfolio review before choosing which event or source record needs action.

## Before You Begin

- Select the organization whose event portfolio you need to review.
- Remember that portfolio values come from the event modules you can access.

## Open the Account Command Center

1. Select **Command Center** in the account sidebar.
2. Use the KPI links, **Timeline Overview**, **Upcoming Deadlines**, financial panels, and **Event Snapshot** to open source work.

## Review Portfolio Health

1. Open Command Center from the account navigation.
2. Review event health and upcoming-event signals.
3. Scan budget, timeline, registration, and speaker readiness information for exceptions.
4. Open the event or linked record that needs follow-up.

## Sort the Event Snapshot

1. Use the snapshot sort to compare events by event, status, budget, timeline, or health.
2. Change sort direction when you need highest-risk or earliest items first.

## Understand Important Concepts

- This is the account-level Command Center. It is different from the Event Command Center inside one event.
- Health indicators summarize current records; they do not replace module-level review.

## In-product Helper Text

> Portfolio health is a starting point. Open an event to validate the records behind each signal.

## Planner Tips

- Begin portfolio reviews with health sorting, then compare the nearest events against budget and timeline signals.

## Best Practices

- Sort Event Snapshot by Health before a portfolio stand-up, then validate exceptions in source modules.
- KPI cards are links to Action Center queues; they are not editable records.

## Troubleshooting

### A control is missing or disabled

Confirm the correct organization is selected and that you can access the events expected to contribute data.

## Frequently Asked Questions

### Where is the system of record?

Portfolio views summarize records from visible events. Open the linked event module before changing or reporting a disputed value.
