# Use Workspace Settings

Manage the display terminology inherited by events in your organization.

## Overview

Account **Settings** currently provides organization-wide **Event terminology** controls. You can change the display labels used for Agenda, Run of Show, Matrix, and Show Flow.

Member administration and external integration controls are not available on this page. Orca does not display inactive controls or link to an unfinished integrations page.

## Before You Begin

- Select the correct organization.
- Confirm that you are authorized to change organization defaults.
- Remember that an event can override these display labels in its own **Settings** page.

## Update Organization Terminology

1. Select **Settings** in the account sidebar.
2. In **Event terminology**, edit one or more display labels.
3. Select **Save terminology**.
4. Wait for the saved confirmation before navigating away.

These changes affect display terminology only. Routes, permissions, analytics, and stored records remain unchanged.

## Understand Event Overrides

Events inherit organization labels unless an event editor selects an event-specific override. Open the event and select **Settings** to inspect or change its inherited values.

## Planner Tips

- Agree on organization vocabulary before active program planning begins.
- Use event overrides sparingly so planners can recognize the same workspace across the portfolio.
- Do not expect organization member management or integration setup on this page; those workflows are not currently available here.

## Troubleshooting

### Settings do not load

Confirm that the correct organization is active and retry the page. If loading fails, the form shows the returned error instead of presenting stale values as saved.

### An event still uses a different label

Open that event's **Settings** and inspect **Event terminology**. A saved event override takes precedence over the organization label.
