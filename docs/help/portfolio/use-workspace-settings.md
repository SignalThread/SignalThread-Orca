# Use Workspace Settings

Understand the current placeholder state of account workspace and organization settings.

## Overview

The current **Settings** page is a placeholder. It does not yet expose organization preferences, integrations, or member management.

## When You’ll Use It

- Open this guide when you need to understand the current placeholder state of account workspace and organization settings.
- Return to it during portfolio review before choosing which event or source record needs action.

## Before You Begin

- Select the organization whose event portfolio you need to review.
- Remember that portfolio values come from the event modules you can access.

## Open Workspace Settings

1. Select **Settings** in the account sidebar.
2. The page currently contains placeholder copy and no editable workspace controls.

## Open Settings

1. Open Settings from account navigation.
2. Review the page state. Current workspace and organization controls are not yet available here.
3. Use Event Settings for supported event-specific configuration.

## Understand Important Concepts

- The current **Settings** page is a placeholder. It does not yet expose organization preferences, integrations, or member management.

## In-product Helper Text

> Workspace and organization settings will appear here when the account settings workflow is released.

## Planner Tips

- Record organization-wide decisions outside this page until controls are shipped; do not assume an event setting applies to every event.

## Best Practices

- Do not assume event settings apply across the organization.
- Use Event Settings only for the selected event's supported Run of Show configuration.

## Troubleshooting

### A control is missing or disabled

Confirm the correct organization is selected and that you can access the events expected to contribute data.

## Frequently Asked Questions

### Where is the system of record?

Portfolio views summarize records from visible events. Open the linked event module before changing or reporting a disputed value.
