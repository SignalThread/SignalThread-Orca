# Use the Action Center

Work through cross-event risks, approvals, deadlines, and budget exposure from one queue.

## Overview

Tasks is hidden because generic tasking is currently disabled.

Deadline results use a limited planning lookahead; Action Center is not a complete historical ledger.

## When You’ll Use It

- Open this guide when you need to work through cross-event risks, approvals, deadlines, and budget exposure from one queue.
- Return to it during portfolio review before choosing which event or source record needs action.

## Before You Begin

- Select the organization whose event portfolio you need to review.
- Remember that portfolio values come from the event modules you can access.

## Open the Action Center

1. From the account **Command Center**, select the **AT RISK**, **BUDGET**, **APPROVALS**, or **DEADLINES** KPI.
2. In Action Center, choose **Risks**, **Approvals**, **Deadlines**, or **Budget**.

## Choose a Queue

1. Open Action Center from the account-level Command Center.
2. Choose Risks, Approvals, Deadlines, or Budget.
3. Review the event, status, owner, due date, and context on each row.
4. Open a row to resolve the work in its source module.

## Understand Important Concepts

- Tasks is hidden because generic tasking is currently disabled.
- Deadline results use a limited planning lookahead; Action Center is not a complete historical ledger.

## In-product Helper Text

> Action Center collects work from source modules. Complete the action in the linked event record.

## Planner Tips

- During a portfolio stand-up, assign the source work in its owning module rather than treating the queue itself as the record of completion.

## Best Practices

- Work the queue by urgency, but complete each item in its linked source module.
- Use **Approvals** for decisions and **Deadlines** for time-based exposure; do not treat them as interchangeable.

## Troubleshooting

### A control is missing or disabled

Confirm the correct organization is selected and that you can access the events expected to contribute data.

## Frequently Asked Questions

### Where is the system of record?

Portfolio views summarize records from visible events. Open the linked event module before changing or reporting a disputed value.
