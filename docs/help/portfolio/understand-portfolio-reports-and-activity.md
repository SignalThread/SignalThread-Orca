# Understand Portfolio Reports and Activity

Understand the current availability of account reporting and event activity pages.

## Overview

Portfolio Reports identifies its future account-level scope but does not currently provide report controls or report data.

Event Activity is Coming soon. Do not rely on it as an audit history.

## When You’ll Use It

- Open this guide when you need to understand the current availability of account reporting and event activity pages.
- Return to it during portfolio review before choosing which event or source record needs action.

## Before You Begin

- Select the organization whose event portfolio you need to review.
- Remember that portfolio values come from the event modules you can access.

## Open Portfolio Reports and Activity

1. Select **Portfolio Reports** in the account sidebar to see the current Preview placeholder.
2. Inside an event, select **Activity** to see its Coming soon state.

## Open the Available Surfaces

1. Open Portfolio Reports from account navigation to view the current account-level placeholder.
2. Open an event's Activity item to view its Coming soon state.
3. Use Command Center, Action Center, Budget, and other source modules for operational reporting today.

## Understand Important Concepts

- Portfolio Reports identifies its future account-level scope but does not currently provide report controls or report data.
- Event Activity is Coming soon. Do not rely on it as an audit history.

## In-product Helper Text

> Preview means the surface is visible but its intended reporting workflow is not complete.

## Planner Tips

- For a current client update, assemble status from Command Center, Roadmap, Budget, Run of Show, and speaker readiness.

## Best Practices

- Build current reports from source modules until Portfolio Reports ships usable controls.
- Do not promise an Event Activity audit trail; the current page is Coming soon.

## Troubleshooting

### A control is missing or disabled

Confirm the correct organization is selected and that you can access the events expected to contribute data.

## Frequently Asked Questions

### Where is the system of record?

Portfolio views summarize records from visible events. Open the linked event module before changing or reporting a disputed value.
