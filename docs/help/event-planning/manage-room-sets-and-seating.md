# Manage Room Sets and Seating

Understand the current availability of Room Set and Seating and use the supported document workflow.

## Overview

**Room Set & Seating** is marked **Coming soon** in the current planner workspace. Planners cannot enable it from Event Settings.

## When You’ll Use It

- Open this guide when you need to confirm Room Set and Seating availability or manage the current document-based alternative.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open Room Sets and Seating

1. Open a session from **Run of Show**.
2. Look for **Room Set & Seating** marked **Coming soon**.
3. Use the current venue-approved diagram in **Documents** for production planning.

## Check Availability

1. Open a session from Run of Show.
2. Look for Room Set & Seating availability in the session modules.
3. Expect the feature to be marked **Coming soon** and unavailable.
4. Open **Documents** to find or upload the current venue-approved room diagram.

## Understand Important Concepts

- Room Set and Seating is not a supported production planning surface today.
- Event Settings cannot enable the feature.

## In-product Helper Text

> Room Set and Seating are coming soon in production.

## Planner Tips

- Continue maintaining venue-approved diagrams in Docs until Room Set & Seating is released in the production workspace.

## Best Practices

- Keep venue-approved diagrams in Documents while production access is unavailable.
- Do not promise in-product seat assignments to onsite teams while the feature is marked **Coming soon**.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

Until Room Set and Seating is released, the venue-approved file in Docs Hub is the authoritative room-layout record.
