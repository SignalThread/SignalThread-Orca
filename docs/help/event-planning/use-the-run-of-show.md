# Use the Run of Show

Plan what happens, when it happens, where it happens, and what each session requires.

## Overview

The active surface is the newer Run of Show workspace; older Matrix routes remain for compatibility.

Quick modules include Details, Speakers, AV, F&B, Staffing, and Conflicts. Room Set and Seating can appear as unavailable or disabled while that feature remains **Coming soon** in production.

Sessions marked **Official agenda** are the approved subset that can be staged in **Reg Agenda**. Unmarked sessions remain internal planning records and are excluded from attendee-facing agenda publication.

## When You’ll Use It

- Open this guide when you need to plan what happens, when it happens, where it happens, and what each session requires.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the Run of Show

1. Open an event and select **Run of Show** under **Planning**.
2. Choose an event **Date**, then select **Board** or **List**.

## Review the Schedule

1. Open Run of Show from the event sidebar.
2. Choose the event date you need to review.
3. Search or filter sessions and scan conflict indicators.
4. Open a session drawer for a quick update or open its full workspace for detailed planning.

## Adjust the Schedule

1. In Board view, confirm the board orientation.
2. Drag a supported session to a new room or time.
3. Review any new conflicts after the move.
4. Open session Details to confirm start, end, and room values.

## Mark the Official Agenda

1. Open a session drawer or full session workspace.
2. Select **Include in official agenda** when the session is approved for attendee-facing use.
3. Save the session.
4. Use the official-agenda filter to review the publishable subset before opening **Reg Agenda**.

Removing the designation keeps the session in Run of Show but removes it from attendee-facing agenda results. If it was previously imported to Registration Agenda staging, the staged entry is archived and unpublished during the next ShowOps import.

## Understand Important Concepts

- The active surface is the newer Run of Show workspace; older Matrix routes remain for compatibility.
- Quick modules include Details, Speakers, AV, F&B, Staffing, and Conflicts. Room Set and Seating can appear as unavailable or disabled while that feature remains **Coming soon** in production.
- Run of Show remains the planning system of record. Registration Agenda stages attendee-facing copies and never turns internal-only sessions into official sessions.

## In-product Helper Text

> Run of Show is the operational schedule. Roadmap tracks planning work and deadlines.

## Planner Tips

- Review schedule shape on the Board, then use List to clean missing fields and compare many sessions.

## Best Practices

- Review room transitions in **Board**, then use **List** for missing-resource cleanup.
- Model meals, rehearsals, breaks, and holds as sessions when they consume time or room capacity.
- Mark only approved attendee-facing sessions as **Official agenda**; keep rehearsals, holds, and internal production cues unmarked unless attendees truly need to see them.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

Run of Show owns session schedule and room placement. Opening a session exposes the same record's detailed speaker, AV, F&B, staffing, file, and onsite planning.
