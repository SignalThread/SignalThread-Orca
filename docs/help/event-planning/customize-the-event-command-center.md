# Customize the Event Command Center

Arrange the event dashboard widgets that matter to your planning review.

## Overview

Layout preferences apply to the event command-center arrangement. They do not change the underlying event data.

Only widgets registered by the current product can be displayed.

## When You’ll Use It

- Open this guide when you need to arrange the event dashboard widgets that matter to your planning review.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open Customize the Event Command Center

1. Open the event **Command Center** and select **Customize dashboard**.
2. Use the customization drawer or edit mode, then select **Done**; use **Reset to Default** only when you want the default arrangement.

## Change the Layout

1. Open the Event Command Center.
2. Enter the available dashboard customization mode.
3. Move or resize supported widgets within the grid.
4. Save the layout so it is used for the event.

## Understand Important Concepts

- Layout preferences apply to the event command-center arrangement. They do not change the underlying event data.
- Only widgets registered by the current product can be displayed.

## In-product Helper Text

> Customize the dashboard layout without changing source records.

## Planner Tips

- Put financial and deadline widgets near the top during active planning; move onsite-readiness information higher as the event approaches.

## Best Practices

- Place the widgets used in recurring client reviews near the top.
- Reset only when the team agrees to abandon the event's current arrangement.

## Troubleshooting

### A widget is not available

The widget may depend on a disabled feature such as generic Tasks, or it may not be registered for the current dashboard.

## Frequently Asked Questions

### Where is the system of record?

The saved dashboard layout controls presentation only. Roadmap, Budget, Run of Show, Docs Hub, and people modules own the records shown in widgets.
