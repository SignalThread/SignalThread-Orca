# Create and Edit Sessions

Add sessions and maintain their schedule, room, type, and operational details.

## Overview

A session can connect to speakers, attendees, requirements, F&B assignments, and budget lines. Room Set and Seating remain **Coming soon** in production.

Session registration controls are Coming soon in production.

## When You’ll Use It

- Open this guide when you need to add sessions and maintain their schedule, room, type, and operational details.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open and Edit Sessions

1. Open **Run of Show** and select **Add session**.
2. To edit, select a session on the board or use the edit control in **List**.

## Create a Session

1. Open Run of Show.
2. Choose Add session.
3. Enter the session title and supported schedule details, including date, start, end, room, and type where applicable.
4. Save and confirm the session appears on the expected date.

## Edit a Session

1. Select the session on Board or List view.
2. Open Details in the quick drawer or the full session workspace.
3. Update supported fields and save.
4. Review Conflicts after changing time, room, or speaker assignments.

## Understand Important Concepts

- A session can connect to speakers, attendees, requirements, F&B assignments, and budget lines. Room Set and Seating remain **Coming soon** in production.
- Session registration controls are Coming soon in production.

## In-product Helper Text

> A session needs accurate date, time, and room data before conflict review is useful.

## Planner Tips

- Create breaks, meals, rehearsals, and holds as sessions when they consume room or timeline capacity.

## Best Practices

- Enter the correct event date before assigning speakers or resources.
- After changing time, room, or speakers, review the session's conflict indicators.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

Run of Show owns the session schedule and room assignment. The full Session Workspace owns that session's detailed resources and operational information.
