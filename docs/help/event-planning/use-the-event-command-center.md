# Use the Event Command Center

Review the health, milestones, budget, program, and readiness of one event.

## Overview

Widget information is derived from event records. Preview labels identify widgets whose presentation is not final.

Generic task summary content is hidden while tasking is disabled.

## When You’ll Use It

- Open this guide when you need to review the health, milestones, budget, program, and readiness of one event.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the Event Command Center

1. Open an event from the account **Command Center**.
2. Select **Command Center** in the event sidebar when you are in another event module.

## Review an Event

1. Open an event to land on its Event Command Center.
2. Scan event identity, dates, and lifecycle context.
3. Review visible widgets for planning exceptions and readiness gaps.
4. Open a widget link to work in the source module.

## Understand Important Concepts

- Widget information is derived from event records. Preview labels identify widgets whose presentation is not final.
- Generic task summary content is hidden while tasking is disabled.

## In-product Helper Text

> The Event Command Center summarizes one event. Source modules remain the detailed record.

## Planner Tips

- Use this page as a meeting agenda, but resolve disputed numbers in Budget, Roadmap, Run of Show, or Speakers.

## Best Practices

- Use the KPI strip to choose what to investigate, then open the linked source module.
- Review this page throughout setup, active planning, onsite preparation, and closeout; it is not only a final-weeks dashboard.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

The Event Command Center summarizes one event. Roadmap, Budget, Run of Show, Docs Hub, and people modules own the records behind its metrics and exceptions.
