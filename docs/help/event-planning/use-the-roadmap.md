# Use the Roadmap

Plan event work across stages, owners, dates, dependencies, priorities, and status views.

## Overview

Critical path identifies work whose timing needs close attention. A blocked predecessor can create downstream risk.

**Board** is useful for status flow; **Matrix** is strongest for scanning and editing; **Workstream** shows timing and dependencies; **Dashboard** summarizes health.

## When You’ll Use It

- Open this guide when you need to plan event work across stages, owners, dates, dependencies, priorities, and status views.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the Roadmap

1. Open an event and select **Roadmap** under **Planning**.
2. Choose **Dashboard**, **Matrix**, **Workstream**, or **Board** from the view control.

## Review Roadmap Work

1. Open Roadmap from the event sidebar.
2. Choose **Dashboard**, **Matrix**, **Workstream**, or **Board** based on the review you need.
3. Filter and search to focus on a workstream, planning stage, owner, status, or priority.
4. Open an item to review and edit supported details.

## Update a Roadmap Item

1. Open the item.
2. Update its title, dates, owner, status, priority, workstream, or planning stage as supported.
3. Review predecessor dependencies before changing critical dates.
4. Save and confirm the item appears in the expected view.

## Understand Important Concepts

- Critical path identifies work whose timing needs close attention. A blocked predecessor can create downstream risk.
- **Board** is useful for status flow; **Matrix** is strongest for scanning and editing; **Workstream** shows timing and dependencies; **Dashboard** summarizes health.

## In-product Helper Text

> Roadmap dates drive deadline and risk signals elsewhere in Orca.

## Planner Tips

- Use planning stages for lifecycle reviews and workstreams for functional ownership. They answer different questions.

## Best Practices

- Use **Matrix** for dense editing, **Board** for status movement, **Workstream** for dates and dependencies, and **Dashboard** for health.
- Put approval decisions in the owning module even when Roadmap tracks the deadline.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

Roadmap owns workstreams, planning items, owners, dates, dependencies, priorities, and statuses. Command Center and Action Center only summarize or link to that work.
