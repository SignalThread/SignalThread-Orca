# Use the Session Workspace

Coordinate a session's schedule, people, requirements, files, F&B, and onsite details in one workspace.

## Overview

The session workspace is the detailed record; the Run of Show drawer is optimized for quick changes.

Requirement templates are configured in Event Settings and can shape session requirement sections.

## When You’ll Use It

- Open this guide when you need to coordinate a session's schedule, people, requirements, files, F&B, and onsite details in one workspace.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the Session Workspace

1. Open **Run of Show**, select a session, and open its full session workspace.
2. Use the section navigation for the schedule, speakers, F&B, requirements, and other available session areas.

## Open a Session Workspace

1. Open Run of Show.
2. Select a session and choose the full workspace action.
3. Use the workspace sections to review details, speakers, requirements, F&B, staffing, conflicts, and available layout tools.

## Check Readiness

1. Confirm title, room, start, and end.
2. Review assigned speakers and conflicts.
3. Review AV, F&B, and staffing requirements.
4. Treat **Room Set & Seating** as unavailable while it is marked **Coming soon**.

## Understand Important Concepts

- The session workspace is the detailed record; the Run of Show drawer is optimized for quick changes.
- Requirement templates are configured in Event Settings and can shape session requirement sections.

## In-product Helper Text

> Open the full workspace when a session needs more than a schedule change.

## Planner Tips

- Use the workspace as the handoff record between program, production, catering, and onsite leads.

## Best Practices

- Use the quick drawer for one change and the full workspace for cross-functional session review.
- Keep the session as the system of record for its schedule and requirements; link Budget lines rather than retyping costs.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

The Session Workspace owns the session's operational details. Event Directory owns person identity, F&B Catalog owns reusable menu items, and Budget owns linked financial records.
