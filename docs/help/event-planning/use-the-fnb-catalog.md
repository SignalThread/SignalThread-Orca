# Use the F&B Catalog

Review existing approved F&B items and understand the limits of the preview catalog screen.

## Overview

F&B Catalog displays existing approved catalog items that sessions can assign. **Source Menus** and **Review & Amendments** are preview-only sections.

Do not rely on **Upload Menu** for production work. Its displayed progress does not create a durable source-menu or approval workflow.

## When You’ll Use It

- Open this guide when you need to review existing approved F&B items and understand the limits of the preview catalog screen.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the F&B Catalog

1. Open `/events/{eventId}/fnb-catalog` directly; it is not in event navigation.
2. Treat **Source Menus** and **Review & Amendments** as preview-only displays.

## Build the Catalog

1. Do not use **Upload Menu** as a production ingestion workflow; its displayed progress is temporary.
2. Maintain source menu files in Documents.
3. Use existing **Approved Catalog Items** for session assignments.
4. If the catalog is empty, keep the current menu in **Documents** and ask your Orca administrator how approved items are provisioned.

## Maintain Catalog Items

1. Search existing approved items using **Search items, source, price...**.
2. Review Item, Category, Current price, Source menu, Updated, and Status.
3. Treat **Review & Amendments** as a preview display, not an actionable queue.

## Understand Important Concepts

- Existing approved items are available to session F&B assignments.
- Menu upload progress, parsed-row approval, and amendments are not durable planner workflows on this screen.
- F&B Catalog is a direct-access preview page and is not listed in event navigation.

## In-product Helper Text

> Approved Catalog Items are available for session assignment.

## Planner Tips

- Keep source-menu names aligned with venue versions so price changes can be traced to the correct banquet document.

## Best Practices

- Use the preview to inspect existing approved items, not to promise a durable menu-import workflow.
- Maintain source menus in Documents until Orca provides a durable catalog-ingestion and amendment workflow.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

F&B Catalog owns existing approved reusable items. Each session's **Session F&B Plan** owns assignments, while Budget owns linked financial records.
