# Choose Board or List View

Choose the Run of Show view that fits visual scheduling or dense record review.

## Overview

Board emphasizes time and room relationships. List emphasizes comparable fields across records.

## When You’ll Use It

- Open this guide when you need to choose the Run of Show view that fits visual scheduling or dense record review.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open Board or List View

1. Open **Run of Show**.
2. Select **Board** for room-and-time placement or **List** for filters and row editing.

## Use Board View

1. Open Run of Show and select Board.
2. Choose rooms-by-time or time-by-room orientation when available.
3. Review session placement, gaps, overlaps, and room flow.
4. Open a session for details before making a consequential move.

## Use List View

1. Select List.
2. Search, sort, and filter by supported session attributes.
3. Scan missing speakers, AV, F&B, staffing, and conflicts.
4. Use available quick or bulk changes for structured cleanup.

## Understand Important Concepts

- Board emphasizes time and room relationships. List emphasizes comparable fields across records.

## In-product Helper Text

> Changing views does not change session data.

## Planner Tips

- Use Board in agenda-design meetings and List in production-readiness reviews.

## Best Practices

- Use **Rooms by time** for venue flow and **Time by room** for moment-by-moment operations.
- Use **List** filters before a readiness meeting to isolate sessions missing speakers, AV, F&B, or staffing.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

Run of Show owns session dates, times, rooms, speakers, and requirements. Board and List are two views of those same session records.
