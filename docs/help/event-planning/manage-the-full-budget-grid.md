# Manage the Full Budget Grid

Create, filter, edit, group, and review event budget line items in a detailed grid.

## Overview

A line may link to a session or operational requirement.

Approved or locked records can be read-only depending on approval state and access.

## When You’ll Use It

- Open this guide when you need to create, filter, edit, group, and review event budget line items in a detailed grid.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the Full Budget Grid

1. Open **Budget** and select **Full Budget Grid**.
2. Use **Search vendor, category, group, or session**, **Filters**, and **Tools** to narrow the grid.

## Edit Budget Lines

1. Open Budget and switch to Full Budget Grid.
2. Search or filter by the available category, group, vendor, session, status, or approval fields.
3. Open or edit a line item and change supported values.
4. Save the change, or discard it before leaving the edit state.

## Work With Multiple Lines

1. Select the relevant rows.
2. Use the available bulk edit controls for a shared field.
3. Review the selected count and resulting values before continuing.

## Understand Important Concepts

- A line may link to a session or operational requirement.
- Approved or locked records can be read-only depending on approval state and access.

## In-product Helper Text

> Filters change the visible grid; they do not delete excluded line items.

## Planner Tips

- Use groups for reporting slices that cut across categories, such as a client option or venue package.

## Best Practices

- Use groups for cross-category reporting and categories for the event's chart of spend.
- Save or discard edited rows before changing filters or entering an approval flow.

## Troubleshooting

### I cannot edit a line item

Check your event role and the line's approval or lock state. Approved records may require a revision workflow.

## Frequently Asked Questions

### Where is the system of record?

The Full Budget Grid owns line-level forecast, actual or committed, category, vendor, approval, and linked-record data.
