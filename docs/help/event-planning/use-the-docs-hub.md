# Use the Docs Hub

Store event documents, organize them by category, link them to planning records, and manage review states.

## Overview

Document status and approval status are separate parts of the review record.

Documents can link to supported event records; a link provides context but does not copy the file.

## When You’ll Use It

- Open this guide when you need to store event documents, organize them by category, link them to planning records, and manage review states.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the Docs Hub

1. Open an event and select **Documents** under **Management**.
2. The page heading is **Docs Hub**; select **Upload Document** or open an existing document card.

## Add a Document

1. Select **Upload Document**.
2. Choose the file and enter **Title**.
3. Select or create **Category**; add Tags and choose visibility if needed.
4. Under **Link to**, optionally choose a Budget item, deadline, or Run of Show session.
5. Optionally enable **Send for Review After Upload**, choose recipients, and add a note.
6. Select **Upload** and confirm the document appears in Docs Hub.

## Run a Document Review

1. Open a document card to display **Document Details**.
2. For a Draft, select reviewers, enter an optional review note, and select **Submit for Review**.
3. For an In Review document that you submitted, select **Pull back** when the control is enabled.
4. Review the status, recipients, activity, and version history in the drawer. Production currently has no planner-facing Approve or Reject control.

## Understand Important Concepts

- Document status and approval status are separate parts of the review record.
- Documents can link to supported event records; a link provides context but does not copy the file.

## In-product Helper Text

> Submit for review when the current file is ready for a decision.

## Planner Tips

- Use categories for durable filing rules and links for the operational context where the document is used.

## Best Practices

- Use categories for filing and **Link to** for Budget item, deadline, or Run of Show session context.
- Submit the current version for review; do not upload a duplicate document merely to restart review.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

Docs Hub owns the uploaded file, metadata, version, and document-review state. Links to Budget, Roadmap, or Run of Show point to records still owned by those modules.
