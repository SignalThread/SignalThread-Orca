# Use the Budget Dashboard

Review forecast, actual spend, targets, categories, groups, and the budget work queue.

## Overview

Forecast is planned spend. Actual is committed or realized spend recorded on the line item. Variance compares those values.

Category targets are planning benchmarks and should not be confused with approved totals.

## When You’ll Use It

- Open this guide when you need to review forecast, actual spend, targets, categories, groups, and the budget work queue.
- Return during early planning, weekly review, client review, final preparation, and closeout whenever this record changes.

## Before You Begin

- Open the correct event and confirm its name and dates.
- Editing requires event editor access; Viewers can inspect supported pages but cannot save protected changes.

## Open the Budget Dashboard

1. Open an event and select **Budget** under **Planning**.
2. Select the dashboard view rather than **Full Budget Grid**.

## Review Budget Health

1. Open Budget from the event sidebar.
2. Stay in Dashboard view.
3. Review forecast and actual totals, variance, category targets, groups, and pending work.
4. Open the Full Budget Grid when a number needs line-level investigation.

## Understand Important Concepts

- Forecast is planned spend. Actual is committed or realized spend recorded on the line item. Variance compares those values.
- Category targets are planning benchmarks and should not be confused with approved totals.

## In-product Helper Text

> Dashboard is for budget health; Full Budget Grid is for line-level work.

## Planner Tips

- Review large variances by category first, then inspect the contributing lines. This keeps a financial review focused on decisions.

## Best Practices

- Review category variance before opening individual lines.
- Use **Actual / Committed** when discussing current exposure; do not describe every amount as paid.

## Troubleshooting

### A control is missing or disabled

Check your event role, the record's current approval or lock state, and whether the documented feature is available in production.

## Frequently Asked Questions

### Where is the system of record?

Budget owns line items and calculated totals. The Budget Dashboard summarizes those records; Account and Event Command Centers summarize them again at a higher level.
