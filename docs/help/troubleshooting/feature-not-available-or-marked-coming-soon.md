# Feature Not Available or Marked Coming Soon

Understand disabled, preview, restricted, placeholder, and coming-soon Orca features.

## Start Here

1. Read the label on the surface: Coming soon means the planner workflow is not available.
2. Preview means the workflow is incomplete and should not be treated as final.
3. A page outside primary navigation may be limited, restricted, or intended only for preview.
4. Generic Tasks and Planner Copilot are disabled by current product configuration.
5. Room Set & Seating is intentionally unavailable in production.
6. Portfolio Reports and the account **Settings** page are placeholder surfaces; **Activity** is **Coming soon** inside each event.
7. Use the related shipped source module instead of relying on unavailable behavior.

## If the Problem Continues

Record the event name, affected record, action you attempted, visible status, and exact error text. Share that context with the appropriate Orca administrator without including secure portal or intake tokens.

## Best Practices

- Use the documented shipped alternative and record the unavailable step outside Orca when necessary.
- Do not treat preview or restricted screens as evidence that a feature is available to planners.
