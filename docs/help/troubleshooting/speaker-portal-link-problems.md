# Speaker Portal Link Problems

Resolve missing, invalid, expired-by-revocation, or misdirected speaker portal access.

## Start Here

1. Confirm the link belongs to the correct speaker and event.
2. Use Preview Portal while signed in as a planner to verify the current speaker view.
3. If the link is invalid or was revoked, generate a new portal link.
4. Copy the generated link when it is shown; Orca displays it once.
5. Send the new link directly to the speaker and remove the old link from draft communications.
6. Do not use the intake link in place of the portal link; they support different workflows.

## If the Problem Continues

Record the event name, affected record, action you attempted, visible status, and exact error text. Share that context with the appropriate Orca administrator without including secure portal or intake tokens.

## Best Practices

- Never include a portal token in a support screenshot or ticket.
- Revoke a misdirected link before generating and sharing its replacement.
