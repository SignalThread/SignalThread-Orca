# Missing Sessions or Schedule Conflicts

Find sessions on the correct date and resolve room or speaker timing conflicts.

## Start Here

1. Confirm you are in the correct event and event date.
2. Clear search and filters in Run of Show.
3. Switch between Board and List to confirm the session exists.
4. If imported, review whether the source row was skipped for missing or invalid timing.
5. Open the session Conflicts module and inspect room or speaker overlap details.
6. Correct date, start, end, room, or speaker assignment, then review conflicts again.

## If the Problem Continues

Record the event name, affected record, action you attempted, visible status, and exact error text. Share that context with the appropriate Orca administrator without including secure portal or intake tokens.

## Best Practices

- Clear Date, search, and List filters before concluding a session is missing.
- After correcting time, room, or speaker assignments, review conflicts again.
