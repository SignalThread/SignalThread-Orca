# Spreadsheet Import Problems

Resolve unreadable files, missing mappings, skipped rows, and unexpected import results.

## Start Here

1. Confirm the file is .xlsx or .csv and can be opened outside Orca.
2. Use a data worksheet rather than a chart, cover sheet, or formatted report tab.
3. Map every required Planner field and set irrelevant columns to Do not map.
4. Open Issues and inspect skipped-row reasons before creating the event.
5. Verify source dates, times, and currency values are stored consistently.
6. If import completed, compare created, updated, conflict, invalid, and skipped counts before retrying.

## If the Problem Continues

Record the event name, affected record, action you attempted, visible status, and exact error text. Share that context with the appropriate Orca administrator without including secure portal or intake tokens.

## Best Practices

- Correct and retry the source once; repeated imports can duplicate valid rows.
- Keep row counts and skipped reasons with the import review until reconciliation is complete.
