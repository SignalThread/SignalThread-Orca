# Missing Notifications

Check unread state, recent-list limits, links, and source records when an expected notification is absent.

## Start Here

1. Open the Notifications bell to force the recent list to load.
2. Remember that the menu shows up to 20 recent notifications.
3. Check whether the item was already opened and marked read.
4. Open Action Center or the source module to verify the underlying approval, deadline, or record state.
5. Refresh the page after a transient loading error.
6. There is no current notification preferences page or Mark all read action.

## If the Problem Continues

Record the event name, affected record, action you attempted, visible status, and exact error text. Share that context with the appropriate Orca administrator without including secure portal or intake tokens.

## Best Practices

- Check Action Center or the source module because the menu is limited to 20 recent items.
- Do not retry the source action solely to create another notification.
