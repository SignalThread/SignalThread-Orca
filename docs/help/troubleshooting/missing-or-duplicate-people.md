# Missing or Duplicate People

Find and correct identity, role, source, import, and duplicate-review issues in Directory, Attendees, or Speakers.

## Start Here

1. Search Directory by name and email without a role filter.
2. Review the person's roles and source labels.
3. Check Attendees or Speakers only after finding the canonical Directory person.
4. Review the latest import counts for conflicts, invalid rows, and skipped rows.
5. Open each possible duplicate and compare identity, roles, and source labels.
6. Correct the inaccurate record or remove an inappropriate role. The current planner UI has no merge control.

## If the Problem Continues

Record the event name, affected record, action you attempted, visible status, and exact error text. Share that context with the appropriate Orca administrator without including secure portal or intake tokens.

## Best Practices

- Search Event Directory without role filters before creating anyone new.
- The current planner UI has no merge control; correct identity and role records individually.
