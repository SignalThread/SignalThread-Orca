# Use Speaker Intake

Request profile updates through a secure speaker-facing form and review the submitted changes.

## Overview

The intake link is token-based and intended for the named speaker. It should not be posted publicly.

Submitted changes can wait for planner review rather than replacing the profile immediately.

## When You’ll Use It

- Open this guide when you need to request profile updates through a secure speaker-facing form and review the submitted changes.
- Return before program publishing, external communication, and onsite handoff when people or readiness data changes.

## Before You Begin

- Open the correct event and search Event Directory before creating a new person.
- Editing requires event editor access; external speaker links do not grant planner access.

## Open Speaker Intake

1. Open a speaker, select **Profile**, and find **Request Profile Update**.
2. Select **Request Profile Update**, then **Copy Link** when the secure intake link appears.

## Send an Intake Link

1. Open the speaker's Profile section.
2. Generate the Speaker-facing intake link.
3. Copy the secure link or open the available draft email when the speaker has an email address.
4. Tell the speaker which fields and deadline matter.

## Review Submitted Changes

1. Return to the speaker Overview or Submissions area.
2. Compare Current and Submitted values.
3. Approve or reject the supported submission.
4. Confirm the accepted profile data appears in the speaker record.

## Understand Important Concepts

- The intake link is token-based and intended for the named speaker. It should not be posted publicly.
- Submitted changes can wait for planner review rather than replacing the profile immediately.

## In-product Helper Text

> Secure intake links let speakers submit profile changes without planner access.

## Planner Tips

- Request profile updates before opening deck requests so the public-facing name, title, organization, and bio are settled first.

## Best Practices

- Request profile updates before finalizing public program copy.
- Review submitted changes before treating the current speaker profile as approved.

## Troubleshooting

### A control is missing or disabled

Check the canonical Directory person, your event role, and any review or token state described in this article.

## Frequently Asked Questions

### Where is the system of record?

Speaker Intake owns the pending submission until a planner approves or rejects it. The approved speaker profile remains the authoritative current record.
