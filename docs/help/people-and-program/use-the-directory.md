# Use the Directory

Maintain the canonical event people list and the roles each person holds.

## Overview

One canonical person can hold several event roles, such as Speaker and Attendee.

Source labels explain how a role or identity entered the event.

## When You’ll Use It

- Open this guide when you need to maintain the canonical event people list and the roles each person holds.
- Return before program publishing, external communication, and onsite handoff when people or readiness data changes.

## Before You Begin

- Open the correct event and search Event Directory before creating a new person.
- Editing requires event editor access; external speaker links do not grant planner access.

## Open the Directory

1. Open an event and select **Event Directory** under **Planning**.
2. Use **Add person**, **Import people**, search, role/status filters, and person drawers.

## Find and Add People

1. Open Directory in the event workspace.
2. Search or filter by role and status.
3. Choose Add person to create a record.
4. Open a person drawer to review identity, roles, sources, and linked context.

## Use Directory Selections

1. Select people or use the current filtered scope.
2. Create a Marketing audience or use the available directory email action.
3. Review the selected scope before continuing.

## Understand Important Concepts

- One canonical person can hold several event roles, such as Speaker and Attendee.
- Source labels explain how a role or identity entered the event.

## In-product Helper Text

> Directory is the canonical people record for the event.

## Planner Tips

- Use one person record with multiple roles. Creating separate speaker and attendee identities causes duplicate communications and reporting.

## Best Practices

- Create one person and add roles rather than duplicating identities.
- Clean missing or invalid email before creating an audience or selecting **Email selected**.

## Troubleshooting

### A control is missing or disabled

Check the canonical Directory person, your event role, and any review or token state described in this article.

## Frequently Asked Questions

### Where is the system of record?

Event Directory owns the canonical person identity, contact details, roles, and source labels used by attendee, speaker, session, and Marketing workflows.
