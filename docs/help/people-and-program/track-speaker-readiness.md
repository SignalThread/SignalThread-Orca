# Track Speaker Readiness

Find missing profile, presentation, travel, dietary, request, and scheduling information before it becomes an onsite issue.

## Overview

Profile completeness is calculated from supported profile fields. It is not proof that every production deliverable is approved.

Pending profile changes can require planner review before the current profile changes.

## When You’ll Use It

- Open this guide when you need to find missing profile, presentation, travel, dietary, request, and scheduling information before it becomes an onsite issue.
- Return before program publishing, external communication, and onsite handoff when people or readiness data changes.

## Before You Begin

- Open the correct event and search Event Directory before creating a new person.
- Editing requires event editor access; external speaker links do not grant planner access.

## Open Track Speaker Readiness

1. Open **Speakers**.
2. Choose **All**, **Missing profile**, **Missing deck**, **Travel / dietary**, **Requests pending**, or **Conflicts**.

## Review Readiness Gaps

1. Open Speakers.
2. Use readiness filters for missing profile, missing deck, travel or dietary gaps, pending requests, and conflicts.
3. Open each speaker with a gap.
4. Resolve the source field, file request, assignment, or schedule issue.

## Understand Important Concepts

- Profile completeness is calculated from supported profile fields. It is not proof that every production deliverable is approved.
- Pending profile changes can require planner review before the current profile changes.

## In-product Helper Text

> Readiness shows missing or pending work that needs planner or speaker follow-up.

## Planner Tips

- Set internal cutoffs earlier than client deadlines: profile first, travel next, deck and onsite changes last.

## Best Practices

- Review profile gaps before publishing program copy and deck gaps before production deadlines.
- A complete profile does not mean files, travel, dietary, or session conflicts are resolved.

## Troubleshooting

### A control is missing or disabled

Check the canonical Directory person, your event role, and any review or token state described in this article.

## Frequently Asked Questions

### Where is the system of record?

The speaker workspace owns profile and deliverable readiness. Run of Show owns the session assignments that contribute schedule conflicts.
