# Understand Attendee and Directory Records

Understand why one person can appear in Directory and a role-specific attendee or speaker view.

## Overview

Directory stores the canonical event identity. Attendees and Speakers add workflow-specific information to that identity.

Deleting a person, changing roles, or requesting an administrative merge can affect role-specific views, so review all roles first.

## When You’ll Use It

- Open this guide when you need to understand why one person can appear in Directory and a role-specific attendee or speaker view.
- Return before program publishing, external communication, and onsite handoff when people or readiness data changes.

## Before You Begin

- Open the correct event and search Event Directory before creating a new person.
- Editing requires event editor access; external speaker links do not grant planner access.

## Open Attendee and Directory Records

1. Open **Event Directory** to inspect the canonical person and roles.
2. Open **Attendees** or **Speakers** for role-specific workflow data.

## Trace a Person Record

1. Find the person in Directory.
2. Review every assigned role and source.
3. Open Attendees or Speakers when you need role-specific workflow fields.
4. Return to Directory for identity cleanup or role review.

## Understand Important Concepts

- Directory stores the canonical event identity. Attendees and Speakers add workflow-specific information to that identity.
- Deleting a person, changing roles, or requesting an administrative merge can affect role-specific views, so review all roles first.

## In-product Helper Text

> One Directory person can support multiple event roles.

## Planner Tips

- When someone is both a speaker and attendee, keep one Directory person and manage their program work in Speakers and participation in Attendees.

## Best Practices

- Change identity and roles in Event Directory; change registration workflow fields in Attendees.
- Keep one Directory person when someone is both an attendee and a speaker.

## Troubleshooting

### A control is missing or disabled

Check the canonical Directory person, your event role, and any review or token state described in this article.

## Frequently Asked Questions

### Where is the system of record?

Event Directory owns one canonical person and that person's roles. Attendees and Speakers add role-specific workflow data without creating separate identities.
