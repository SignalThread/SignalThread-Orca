# Use the Speaker Portal

Give a speaker secure access to their profile, presentations, required documents, and messages.

## Overview

The planner preview is read-only. It cannot perform speaker actions.

Invalid or revoked tokens are rejected.

## When You’ll Use It

- Open this guide when you need to give a speaker secure access to their profile, presentations, required documents, and messages.
- Return before program publishing, external communication, and onsite handoff when people or readiness data changes.

## Before You Begin

- Open the correct event and search Event Directory before creating a new person.
- Editing requires event editor access; external speaker links do not grant planner access.

## Open the Speaker Portal

1. Open a speaker's **Overview** and find the **Speaker Portal** card.
2. Select **Generate Portal Link**, **Preview Portal**, **Copy Link**, or **Revoke Link** as needed.

## Generate and Share Portal Access

1. Open the speaker Overview.
2. Generate a Speaker Portal link.
3. Copy the link when Orca displays it; the generated link is shown once.
4. Use Preview Portal to inspect the speaker's read-only view before sending.

## Revoke Access

1. Open the Speaker Portal access card.
2. Revoke the current link when it was sent to the wrong person or should no longer work.
3. Generate a new link if access is still required.

## Understand Important Concepts

- The planner preview is read-only. It cannot perform speaker actions.
- Invalid or revoked tokens are rejected.

## In-product Helper Text

> Portal links are secure and speaker-specific. A generated link is shown once.

## Planner Tips

- Send portal links individually and identify the event in the message. Regenerate promptly if a link enters an unintended thread.

## Best Practices

- Preview the portal before sharing it and send each token only to its intended speaker.
- Regenerate or revoke a link immediately when it reaches the wrong recipient.

## Troubleshooting

### A control is missing or disabled

Check the canonical Directory person, your event role, and any review or token state described in this article.

## Frequently Asked Questions

### Where is the system of record?

The portal presents speaker-facing views of the speaker profile, assigned sessions, messages, presentations, and document requests. Planners maintain those records in the speaker workspace and Run of Show.
