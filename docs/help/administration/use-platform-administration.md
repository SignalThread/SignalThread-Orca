# Use Platform Administration

Invite and provision platform users when you have SUPER_ADMIN access.

## Overview

This area is for platform provisioning, not routine event staffing or attendee management.

Normal planners should not expect to see this route.

## When You’ll Use It

- Open this guide when you need to invite and provision platform users when you have SUPER_ADMIN access.
- Return only when platform access must be provisioned or corrected.

## Before You Begin

- You must have the SUPER_ADMIN platform role.

## Open Platform Administration

1. Sign in with a **SUPER_ADMIN** account and open **Platform Users**.
2. Use **Invite and Provision User** only for platform-level onboarding.

## Invite a Platform User

1. Open Platform Users in the administration area.
2. Choose the destination organization in the invite form.
3. Enter **Email**, choose **Organization** and **Role**, then select **Invite user**.
4. Confirm the result before sharing access expectations with the user.

## Understand Important Concepts

- This area is for platform provisioning, not routine event staffing or attendee management.
- Normal planners should not expect to see this route.

## In-product Helper Text

> Platform Users is restricted to SUPER_ADMIN accounts.

## Planner Tips

- Grant the narrowest access that lets the person complete their role, then verify the organization context with them.

## Best Practices

- Choose the narrowest organization role that supports the person's work.
- Verify the organization before selecting **Invite user**; the action provisions access beyond a single event.

## Troubleshooting

### A control is missing or disabled

Non-SUPER_ADMIN users are redirected to the account Command Center. Verify the platform role before retrying.

## Frequently Asked Questions

### Where is the system of record?

Platform Administration owns user provisioning; Event Directory and Staffing are not access-management tools.
