## 📝 Implementation Details

### Tailwind Classes Added
- `shadow-sm` - Subtle elevation for cards
- Light mode variants for all backgrounds/borders/text
- Proper color token progression (900 → 700 → 600 → 500)

### SVG Dynamic Styling
- Replaced inline stroke colors with Tailwind classes
- Used `className="stroke-zinc-200 dark:stroke-zinc-700"`
- Ensures chart adapts to theme

### Status Color System
- Light mode: 700 text + 50 bg + 300 border (high contrast)
- Dark mode: 400 text + 900/30 bg + 800 border (preserved)
- Consistent across Pulse, severity pills, and variants
