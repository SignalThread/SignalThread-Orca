## ❌ Original Problem

**Error during `npx prisma migrate reset`:**
```
ERROR: column "locationId" does not exist
ERROR: column "eventType" does not exist
ERROR: column "anonymousId" does not exist
```

### Root Cause

The migration used `CREATE TABLE IF NOT EXISTS` for tables that already existed from previous migrations:
- `Event` (existed from `20260109031658_init`)
- `Response` (existed from `20260109031658_init`)
- `Answer` (existed from `20260109031658_init`)

**Problem Flow:**
1. `CREATE TABLE IF NOT EXISTS "Event"` with new columns → **skipped** (table exists)
2. New columns (`locationId`, `eventType`, etc.) → **not added**
3. `CREATE INDEX IF NOT EXISTS "Event_locationId_idx"` → **FAILED** (column doesn't exist)

## 🎯 Key Learnings

### CREATE TABLE IF NOT EXISTS Pitfall

```sql
-- ❌ WRONG: Assumes table doesn't exist
CREATE TABLE IF NOT EXISTS "Event" (
    "id" TEXT PRIMARY KEY,
    "locationId" TEXT NOT NULL,  -- Only added if table doesn't exist
    ...
);

-- Later...
CREATE INDEX "Event_locationId_idx" ON "Event"("locationId");  -- FAILS if column doesn't exist!
```

```sql
-- ✅ CORRECT: Handle both cases
CREATE TABLE IF NOT EXISTS "Event" (
    "id" TEXT PRIMARY KEY,
    "locationId" TEXT NOT NULL,
    ...
);

-- Add column in case table already exists
ALTER TABLE "Event" ADD COLUMN IF NOT EXISTS "locationId" TEXT;

-- Now this always works
CREATE INDEX IF NOT EXISTS "Event_locationId_idx" ON "Event"("locationId");
```

### Migration Ordering Rules

1. **Create ENUMs first** (needed for column types)
2. **Create or alter tables second** (ensure columns exist)
3. **Create indexes third** (reference existing columns)
4. **Add foreign keys last** (reference existing tables and columns)

### Idempotent Migration Pattern

```sql
-- Pattern for additive migrations that work on both new and existing databases:

-- 1. Create enum (idempotent)
DO $$ BEGIN
  CREATE TYPE "MyEnum" AS ENUM ('VALUE');
EXCEPTION
  WHEN duplicate_object THEN NULL;
END $$;

-- 2. Create table (idempotent)
CREATE TABLE IF NOT EXISTS "MyTable" (
    "id" TEXT PRIMARY KEY,
    "newColumn" TEXT
);

-- 3. Add column (idempotent, handles existing table)
ALTER TABLE "MyTable" ADD COLUMN IF NOT EXISTS "newColumn" TEXT;

-- 4. Create index (idempotent)
CREATE INDEX IF NOT EXISTS "MyTable_newColumn_idx" ON "MyTable"("newColumn");

-- 5. Add foreign key (idempotent)
DO $$ BEGIN
  ALTER TABLE "MyTable" ADD CONSTRAINT "MyTable_fk" 
    FOREIGN KEY ("newColumn") REFERENCES "OtherTable"("id");
EXCEPTION
  WHEN duplicate_object THEN NULL;
END $$;
```
