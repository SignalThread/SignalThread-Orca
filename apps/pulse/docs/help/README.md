## Notes

- The app uses both `Survey` and `Event` internally in code. These docs use the customer-facing term `Survey`.
- `Location/Team` means the place or group where feedback is collected.
- Question voice settings are part of the normal survey save flow. There is no separate audio generation step in the UI.
