# Creating a Survey

Use this guide to create a new survey and prepare it for kiosk feedback collection.

## Where To Go

From the dashboard:

1. Click `Create Survey`

You can also reach the survey creator from the Help page quick links.

## What You Can Set Up

The create flow includes:

- Survey name
- Description
- Location/Team
- Questions
- Question Voice

## Step-by-Step

### 1. Enter the survey name

Add a clear name such as:

- `Customer Feedback`
- `Store Experience Survey`
- `Post-Service Check-In`

The name is required.

### 2. Add a description

This is optional. Use it to remind your team what the survey is for.

What this means:

- The description helps with internal organization.
- It is not the main thing kiosk visitors focus on.

### 3. Choose a Location/Team

If you already have one:

1. Select it from the list

If you do not have one yet:

1. Create it inside the same flow
2. Enter the name
3. Add address details if relevant
4. Save it

## Adding Questions

The survey must have at least one question before it can be saved.

You can:

- add questions manually
- reorder questions
- delete questions
- use the built-in AI question generator

### Manual questions

Add plain-language prompts that are easy to answer out loud.

Good examples:

- `How was your experience today?`
- `What went well?`
- `What could we improve next time?`

### AI-generated questions

The app includes an AI question generator inside the question builder.

Current options in code include:

- business type
- goal
- tone
- number of questions

What this means:

- You can start fast with a question set, then edit it before saving.

## Choose Question Voice

The create flow includes a `Question Voice` section inside the questions card.

You can choose:

- `Gender`
- `Voice`
- `Preview Voice`

When you click `Preview Voice`, the app plays a sample line using the current voice selection.

Important:

- Voice preview works before the survey is saved.
- Audio is generated automatically when you save the survey.

## Save the Survey

When you click `Create Survey`:

1. The survey is created in `DRAFT` status
2. Questions are saved
3. The selected voice settings are saved to the survey
4. Cached question audio is generated automatically

What this means:

- There is no separate “generate audio” task for admins.
- Your selected question voice becomes part of the survey setup.

## If the Survey Will Not Save

Check these common issues:

- survey name is blank
- no location/team is selected
- no questions were added
- one or more questions are blank
- your session is missing the `account` context
