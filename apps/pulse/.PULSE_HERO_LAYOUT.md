## 🎯 Goal

## 🏗️ Implementation

### Layout Container (Retail Only)

```tsx
{isRetail ? (
  <>
    {analysisData.completedResponses > 0 && pulse ? (
      /* Hero Layout: Pulse + KPIs side-by-side */
      <div className="grid grid-cols-1 lg:grid-cols-3 gap-4 mb-4">
        {/* Pulse: Large, hero (2/3 width) */}
        <div className="lg:col-span-2">
          <PulseModule pulse={pulse} days={timePeriod} />
        </div>

        {/* KPIs: Stacked vertically (1/3 width) */}
        <div className="flex flex-col gap-3">
          <KPICard label="Responses (Last Xd)" value="..." />
          <KPICard label="Sentiment" value="..." />
          <KPICard label="Sentiment Score" value="..." />
          <KPICard label="Answers" value="..." />
        </div>
      </div>
    ) : (
      /* No data: Original grid */
      <div className="grid grid-cols-2 md:grid-cols-4 gap-3 mb-4">
        {/* 4 KPIs in grid */}
      </div>
    )}
  </>
) : (
  /* Non-retail: Original grid (unchanged) */
  <div className="grid grid-cols-2 md:grid-cols-4 gap-3 mb-4">
    {/* 4 KPIs in grid */}
  </div>
)}
```

### Grid System

**Tailwind Grid:**
```css
grid-cols-1        /* Mobile: 1 column (stack) */
lg:grid-cols-3     /* Desktop: 3 columns */

/* Pulse spans 2 of 3 columns (2/3 width) */
lg:col-span-2

/* KPIs take 1 of 3 columns (1/3 width) */
/* No span needed, default 1 column */
```

### KPI Stack

**Flexbox Column:**
```css
flex flex-col gap-3
```

- `flex flex-col`: Vertical stacking
- `gap-3`: 12px spacing between KPI cards
- Each KPI card full width of container

- **Label:** Dynamic based on time period (30d/60d/90d)
- **Value:** Completed responses count
- **Purpose:** Volume indicator

### 2. Sentiment
- **Label:** "Sentiment"
- **Value:** Overall sentiment label (e.g., "Mostly Positive")
- **Purpose:** Qualitative signal

### 3. Sentiment Score
- **Label:** "Sentiment Score"
- **Value:** Numeric score (0-100)
- **Purpose:** Quantitative sentiment metric

### 4. Answers
- **Label:** "Answers"
- **Value:** Completed / Total (e.g., "92/100")
- **Purpose:** Completion tracking

```tsx

  /* Hero layout: Pulse + KPIs side-by-side */
```

**Why?**
- If no responses yet, Pulse has no score to display
- Falls back to original grid layout for KPIs

## 🎨 Design Rationale

### Why 2/3 - 1/3 Split?

**Pulse (2/3):**
- ✅ Needs space for circular ring (160px)
- ✅ Needs space for status, delta, drivers
- ✅ Should be visually dominant (hero)
- ✅ 2/3 width provides breathing room

**KPIs (1/3):**
- ✅ Compact cards with label + value only
- ✅ 4 cards stacked = ~320-400px total height
- ✅ 1/3 width sufficient for readability
- ✅ Creates asymmetric, intentional hierarchy

### Why Not 50-50?

- ❌ Would make Pulse less dominant
- ❌ Would give too much space to KPIs
- ❌ Would weaken visual hierarchy
- ✅ 2/3 - 1/3 is more intentional and bold

### Why Stack KPIs Vertically?

- ✅ Aligns with Pulse height (full-height)
- ✅ Creates visual harmony
- ✅ All metrics visible without scrolling
- ✅ Natural reading flow (top to bottom)
- ✅ Responsive (already vertical on mobile)
