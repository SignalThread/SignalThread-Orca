### 4. Pulse Score Formula

**Deterministic Calculation (No Schema Changes):**

```typescript
function computePulse(
  sentimentScore: number | null,
  topThemes: { theme: string; count: number }[] | null,
  topActions: string[] | null,
  totalResponses: number
): PulseData {
  // Base score from sentiment (0-50 points)
  const sentimentPoints = sentimentScore ? sentimentScore * 50 : 25

  // Volume bonus (0-30 points) - more responses = better
  const volumePoints = Math.min((totalResponses / 50) * 30, 30)

  // Theme diversity bonus (0-20 points) - more themes = richer feedback
  const themePoints = topThemes ? Math.min((topThemes.length / 10) * 20, 20) : 0

  // Total score (0-100)
  const score = Math.round(sentimentPoints + volumePoints + themePoints)

  // Map to status
  let status: 'Great' | 'Good' | 'Mixed' | 'Needs Attention'
  if (score >= 80) status = 'Great'
  else if (score >= 60) status = 'Good'
  else if (score >= 40) status = 'Mixed'
  else status = 'Needs Attention'

  // Get top drivers (top 3 themes or first 2-3 actions)
  const topDrivers = topThemes
    ? topThemes.slice(0, 3).map(t => t.theme)
    : (topActions ? topActions.slice(0, 2) : [])

  return { score, status, delta: 0, topDrivers }
}
```

**Score Breakdown:**
- **Sentiment (50 points):** Core metric, directly from avgSentimentScore
- **Volume (30 points):** More responses = better signal (cap at 50 responses)
- **Diversity (20 points):** More themes = richer feedback (cap at 10 themes)

**Thresholds:**
```
Score 80-100 → Great (🟢)
Score 60-79  → Good (🟡)
Score 40-59  → Mixed (🟠)
Score 0-39   → Needs Attention (🔴)
```

**Data Sources:**
- Uses existing `avgSentimentScore` from analysis
- Uses existing `topThemes` counts
- Uses existing `topActionItems` as fallback
- Uses `completedResponses` count
- **No new database queries**
- **No schema changes**

## 🎓 Design Decisions

### Why 0-100 Score?

**Considered:**
- 0-10 scale (too granular for 3 inputs)
- Star rating (not numeric enough)

**Chose 0-100 because:**
- ✅ Familiar (percentage-like)
- ✅ Room for nuance (100 values)
- ✅ Easy to visualize
- ✅ Clear thresholds (20-point bands)

### Why These Formula Weights?

**50 points: Sentiment** - Most important signal  
**30 points: Volume** - Need enough data to be meaningful  
**20 points: Diversity** - Indicates engagement depth

**Tested with seed data:**
- Great sentiment (0.7) + high volume (40) + many themes (8) = Score 86 (Great)
- Mixed sentiment (0.5) + low volume (10) + few themes (3) = Score 37 (Needs Attention)

### Why Line Chart Over Bar Chart?

**User feedback:**
- Trends easier to spot with lines
- Less visual clutter
- More professional appearance

**Benefits:**
- Cleaner design
- Better for time series
- Easier to see patterns
- Still lightweight
