# Pulse v2: Enhanced Module with Circular Ring

**Date:** 2026-01-26  
**Status:** ✅ COMPLETE

---

## 🎯 Requirements

Enhance the existing Pulse module (retail-only) with:

1. ✅ **Circular Ring Graphic** - Strong visual around the score (0-100)
2. ✅ **Score Display** - Large 0-100 integer in center of ring
3. ✅ **Status Label** - Great / Good / Mixed / Needs Attention
4. ✅ **Delta** - vs prior period (same window length: +6 / -4)
5. ✅ **Driver Chips** - Up to 3 only, derived from themes/actions
6. ✅ **Driver Fallback** - "Not enough consistent signals yet" when no drivers
7. ✅ **Lightweight** - CSS/SVG only, no new dependencies
8. ✅ **Retail-Only** - Conditional rendering, not shown on events dashboards
9. ✅ **Time Selector** - 30/60/90d continues to drive all metrics
10. ✅ **Light/Dark Mode** - Both themes look good

#### 2. SVG Circular Ring
```tsx
// Ring calculation
const size = 160
const strokeWidth = 12
const radius = (size - strokeWidth) / 2
const circumference = 2 * Math.PI * radius
const progress = (pulse.score / 100) * circumference
const offset = circumference - progress

// SVG structure
<svg className="transform -rotate-90" width={size} height={size}>
  {/* Background ring */}
  <circle
    cx={size / 2}
    cy={size / 2}
    r={radius}
    fill="none"
    className="stroke-zinc-200 dark:stroke-zinc-700"
    strokeWidth={strokeWidth}
  />
  
  {/* Progress ring (dark mode) */}
  <circle
    className="hidden dark:block"
    stroke={config.ringColorDark}
    strokeDasharray={circumference}
    strokeDashoffset={offset}
    strokeLinecap="round"
    style={{ transition: 'stroke-dashoffset 0.5s ease' }}
  />
  
  {/* Progress ring (light mode) */}
  <circle
    className="block dark:hidden"
    stroke={config.ringColor}
    strokeDasharray={circumference}
    strokeDashoffset={offset}
    strokeLinecap="round"
    style={{ transition: 'stroke-dashoffset 0.5s ease' }}
  />
</svg>

{/* Score in center */}
<div className="absolute inset-0 flex flex-col items-center justify-center">
  <span className={`text-4xl font-bold ${config.color}`}>{pulse.score}</span>
  <span className="text-[10px] font-semibold text-zinc-500 dark:text-zinc-400 uppercase tracking-wide">
    Score
  </span>
</div>
```

## 🧮 Driver Logic

### computePulse Function (Unchanged)
```tsx
// Get top drivers (top 3 themes or first 2-3 actions)
const topDrivers: string[] = []
if (topThemes && topThemes.length > 0) {
  topDrivers.push(...topThemes.slice(0, 3).map(t => t.theme))
} else if (topActions && topActions.length > 0) {
  topDrivers.push(...topActions.slice(0, 2))
}

return { score, status, delta, topDrivers }
```

### Display Logic (New)
```tsx
// Always limit to 3 for display (safety, already limited in compute)
const driversToShow = pulse.topDrivers.slice(0, 3)

// Show fallback if no drivers
if (driversToShow.length === 0) {
  // Show: "Not enough consistent signals yet"
}
```

### Rules Applied
✅ **Up to 3 drivers** - slice(0, 3) ensures max 3  
✅ **Prefer themes** - Use themes first, fallback to actions  
✅ **Show fewer if less available** - No padding, just show what exists  
✅ **Show none with message** - Fallback text when empty array  
✅ **Derived from existing data** - No new API calls, uses themes/actions from analysis

## 📐 Technical Details

### SVG Math
```
Circumference = 2 × π × radius
              = 2 × π × 74
              ≈ 465px

Progress = (score / 100) × circumference
Offset = circumference - progress

Example: score = 85
  progress = 0.85 × 465 ≈ 395px
  offset = 465 - 395 = 70px
  
stroke-dasharray: 465 (total length)
stroke-dashoffset: 70 (starts 70px from beginning, shows 395px)
```

### Rotation
```css
transform: -rotate-90
```
Rotates ring to start at top (12 o'clock) instead of right (3 o'clock)

### Animation
```css
transition: stroke-dashoffset 0.5s ease
```
Smooth progress animation when score changes (e.g., on time period switch)

## 🎨 Design Decisions

### Why Circular Ring?
- ✅ **Strong visual anchor** - Draws eye to score
- ✅ **Progress indication** - 0-100 intuitive as circle fill
- ✅ **Modern aesthetic** - Common in dashboards (Fitbit, Apple Watch)
- ✅ **Compact** - Fits score + label in small space

### Why SVG vs Canvas?
- ✅ **Declarative** - Easier to maintain
- ✅ **Responsive** - Scales with viewport
- ✅ **CSS integration** - Tailwind classes work
- ✅ **Accessibility** - Screen readers can parse

### Why Two Circles (Light/Dark)?
- ✅ **Theme consistency** - 700 (light) vs 400 (dark) tones
- ✅ **High contrast** - Both modes readable
- ✅ **No JS theme detection** - Tailwind handles with classes
- ✅ **No flicker** - CSS shows/hides instantly

### Why Limit to 3 Drivers?
- ✅ **Focus** - Too many = overwhelming
- ✅ **Space** - Fits cleanly on one line (desktop)
- ✅ **Signal** - Top 3 are most actionable
- ✅ **Consistency** - Matches industry patterns (dashboards show 3-5 items)
