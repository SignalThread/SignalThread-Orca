# View a Voice Note Transcript

Transcripts make recorded context reviewable after the conversation. Use them to confirm what was said, understand why AI Insights changed, or refresh your memory before follow-up.

---

## Open a Transcript

1. Open a lead from **Leads**.
2. In the **Overview** tab, tap **View all notes**.
3. Find a note marked **Transcript ready**.
4. Tap the document icon.
5. Review the transcript in the modal.

Tap **Close** to return to the voice notes list.

---

## When Transcripts Are Available

A transcript is available once the note reaches **Transcript ready**. Notes that are uploading or processing cannot be opened yet.

If processing is still in progress, return after a short wait and refresh the lead.

---

## Transcript Accuracy

Transcripts are generated automatically. Background noise, distance from the phone, accents, and technical terms can affect accuracy.

If a transcript misses an important detail, add a context voice note with the correction so AI Insights have the right information.

---

## Common Issues

**The document icon is unavailable.**
The transcript is not ready yet.

**The transcript is incomplete or incorrect.**
Add a brief context note summarizing the accurate detail.

**The modal shows a placeholder.**
Close it, wait for processing to finish, and refresh the lead.
