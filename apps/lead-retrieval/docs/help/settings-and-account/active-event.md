# Active Event

Your active event determines where new leads, scans, and notes are saved. Confirm it before you start capturing so every conversation lands in the right event workspace.

---

## Set the Active Event

1. Go to **Settings**.
2. Open **Active Event**.
3. Select the event you are working.
4. Return to capture.

All new leads are attributed to the selected event.

---

## Why It Matters

Event teams often work across multiple shows, demos, or customer programs. The active event keeps capture, reporting, and follow-up organized so leads do not end up in the wrong pipeline.

---

## Changing Events During a Show

If you switch events, confirm the new selection before scanning or recording. Existing leads remain with the event where they were captured.

---

## Offline Behavior

If you are offline, the app shows the last saved event and profile. You can keep working, and updates sync when connection returns.

---

## Common Issues

**The event I need is missing.**
Confirm your admin has granted access to the event.

**Leads went to the wrong event.**
Contact your admin or support for help reviewing event access and cleanup options.
