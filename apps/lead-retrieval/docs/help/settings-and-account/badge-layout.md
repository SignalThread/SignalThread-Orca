# Badge Layout

Badge layout learning helps SignalThread Scan improve accuracy for the specific badge format used at your event. If scans start placing information in the wrong fields, reset the learned layout so the app can recalibrate.

---

## What Badge Layout Means

Events use different badge designs. Names, companies, titles, barcodes, and QR codes can appear in different places. As your team scans, the app learns the event's layout so future captures are parsed more reliably.

---

## Check Layout Status

1. Go to **Settings**.
2. Find **Capture Settings**.
3. Review **Learned badge layout**.

Status options:

- **Active** - a layout is learned for the current event
- **Not learned** - the app has not learned a layout yet

The event name appears with the status so you can confirm you are looking at the right event.

---

## Reset the Layout

Reset the layout when scans look scrambled, fields are consistently wrong, or the event changes badge formats mid-show.

1. Go to **Settings** > **Capture Settings**.
2. Tap **Reset learned badge layout**.
3. Wait for the confirmation toast.

The next few scans help establish a fresh layout.

---

## Common Issues

**Scans are mapping to the wrong fields.**
Reset the layout and scan a few clear badges.

**Status is "Not learned" after several scans.**
Confirm the correct active event is selected.

**Reset does not finish.**
Check your connection and try again.
