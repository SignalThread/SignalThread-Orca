# People Data Labs Integration

The People Data Labs integration stores an API key for company-level lead profile enrichment.

Status: live API key setup and disconnect are implemented.

---

## What It Does

People Data Labs can enrich lead profiles with contact and company data when configured as an enrichment provider.

---

## Who Can Configure It

Exhibitor Admins with company access can configure People Data Labs.

---

## Where to Configure It

Open **Admin Portal → Integrations → People Data Labs**.

Paste the API key and save it. The stored key can later be replaced or disconnected.

---

## Default Enrichment Provider

When connected, People Data Labs can be selected as the default enrichment provider for the company workspace.

---

## Common Issues

**Missing API key.**
Enter a valid key before saving.

**Default provider cannot be set.**
Connect the provider first.

**Disconnect did not work.**
Refresh the page and try again. If it still appears connected, contact support with the company and event name.
