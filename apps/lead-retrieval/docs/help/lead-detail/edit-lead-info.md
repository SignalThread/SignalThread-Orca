# Edit Lead Info

Clean lead data is what makes follow-up useful. Update contact details as soon as you notice a missing field, typo, or scan mismatch so the rest of your team can trust the record.

---

## Edit Key Fields

Some details can be updated directly from the lead card:

- **Name** - tap the name to edit it
- **Job title** - tap the title to edit it

Tap away from the field when you are finished.

---

## Edit Contact Details

In the **Overview** tab, tap the **Email** or **Phone** field to edit it inline. This is the fastest way to correct scan errors before outreach begins.

---

## Save Changes

When a field changes, a **Save** button appears in the header. Tap **Save** to apply updates.

- **Saving...** means the update is in progress
- **Saved** confirms the record has been updated

If an email address is not formatted correctly, the app shows a validation message below the field.

---

## Fields Managed Elsewhere

Some information is controlled by capture data, enrichment, or event systems:

- **Company** - captured at lead creation or edited from the list workflow
- **Enrichment data** - pulled from available public sources
- **Status** - managed by the event platform

For broader edits, long-press a lead in the **Leads** list to open the edit modal.

---

## Common Issues

**Changes did not save.**
Make sure you tapped **Save** and have a stable connection.

**Email validation appears.**
Check the format, for example `name@company.com`.
